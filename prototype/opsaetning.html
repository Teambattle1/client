Sæt sitet op på Netlify

        
Her bygges portalen, og her fortæller du den, hvor databasen står.

      

    

    


      

        
✓

        

          Opret sitet ud fra repoet
          Add new site → Import an existing project → GitHub → vælg Teambattle1/client.
                Byggeindstillingerne udfylder sig selv — de ligger i repoet.
          Åbn Netlify →
          Se repoet
        

      


      

        
✓

        

          Hent de to værdier i Supabase
          I Supabase: Project Settings → API. Du skal bruge Project URL og nøglen der hedder anon public.
                Den nøgle er offentlig med vilje — den ligger i enhver besøgendes browser.
          Åbn API-siden →
        

      


      

        
✓

        

          Skriv dem ind i Netlify
          På sitet: Site configuration → Environment variables → Add a variable.
                Navnene skal staves præcis sådan her:
          
VITE_SUPABASE_URL

          
VITE_SUPABASE_ANON_KEY

        

      


      

        
✓

        

          Byg sitet igen
          Deploys → Trigger deploy → Deploy site.
        

      


      
!
        Det sidste hak er ikke til pynt. De to nøgler bages ind, når sitet bygges — så et site,
              der allerede var bygget, kender dem ikke. Springer du det over, ser portalen helt rigtig ud,
              men den finder ingen kunder, og du tror databasen er gået galt.

Sæt adressen på

        
Så portalen ligger på client.eventday.dk og ikke på et tilfældigt Netlify-navn.

      

    

    


      

        
✓

        

          Tilføj adressen i Netlify
          På sitet: Domain management → Add a domain → skriv client.eventday.dk.
                Netlify svarer med den linje, der skal ind hos jeres DNS.
          
client.eventday.dk

        

      


      

        
✓

        

          Læg linjen ind hos jeres DNS
          Samme sted som flow.eventday.dk og track.eventday.dk er sat op — det er typisk
                en CNAME, der peger på jeres Netlify-adresse.
        

      


      

        
✓

        

          Vent på hængelåsen
          Netlify henter selv et sikkerhedscertifikat, når DNS er slået igennem. Det tager typisk
                minutter, men kan tage timer. Der er ikke noget at gøre imens.
